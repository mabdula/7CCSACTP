   8 text ‹\Exercise{Fold function}
   9   The fold function is a very generic function, that can be used to express 
  10   multiple other interesting functions over lists.
  11 ›
  12 
  13 text ‹Have a look at Isabelle/HOL's standard function @{const ‹fold›}, defined as follows:›
  14 
  15 fun fold::"('a ⇒ 'b ⇒ 'b) ⇒ 'a list ⇒ 'b ⇒ 'b" where
  16 "fold f [] acc = acc"
  17 | "fold f (x #xs) acc = fold f xs (f x acc)"
  18 
  19 text ‹
  20   Write a function to compute the sum of the elements of a list. 
  21   Define two versions, one direct recursive definition, and one using fold.
  22   Show that both are equal.
  23 
  24   Hint: use automation!
  25 ›  
  26 
  27 fun list_sum :: "nat list ⇒ nat" 
  28   (*<*)  
  29   where
  30     "list_sum [] = 0"
  31   | "list_sum (x#xs) = x + list_sum xs"  
  32     (*>*)  
  33 
  34 
  35 (*
  36   Mention that definition can be used for non-recursive functions. It does not add the function
  37   definition to the simp set.
  38 *)
  39 definition list_sum' :: "nat list ⇒ nat"
  40   (*<*)  
  41   where "list_sum' xs ≡ fold (+) xs 0"
  42   (*>*)    
  43 
  44 (*<*)    
  45 lemma aux: "fold (+) xs a = list_sum xs + a"  
  46   by (induction xs arbitrary: a) auto
  47     (*>*)    
  48 
  49 lemma "list_sum xs = list_sum' xs"
  50   (*<*)    
  51   unfolding list_sum'_def by (simp add: aux)
  52   (*>*)

  54 text ‹\Exercise{Tail recursive ‹reverse›}
  55 In Isabelle, there is the reverse function @{const rev}, which, given a list, computes another list
  56 with the same elements but in reverse order.
  57 Take a loot into its definition:
  58 ›
  59 
  60 thm rev.simps  
  61 
  62 text ‹
  63   Recall tail recursion: a function is tail recursive if in all recursive calls it does not call 
  64   anything after itself\footnote{See \url{https://en.wikipedia.org/wiki/Tail_call.} for a quick review.}.
  65   For instance, the implementaion of @{const rev} in Isabelle is not tail recursive, because it calls
  66   @{const append} after it calls @{const rev} in the second equation.
  67   
  68   Write an alternative implementation of the reverse function that is tail recursive.
  69 
  70   Hint: recall that you can most of the times derive a tail recursive function using an accumulator
  71         argument. 
  72 
  73 ›  
  74 
  75 (*<*)
  76 fun rev'::"'a list ⇒ 'a list ⇒ 'a list" where
  77   "rev' [] acc = acc"
  78 | "rev' (x #xs) acc = rev' xs (x # acc)"
  79 (*>*)
  80 
  81 
  82 (*show definition vs fun*)
  83 fun rev_tr::"'a list ⇒ 'a list" where
  84 (*<*)
  85   "rev_tr xs = rev' xs []"
  86 (*>*)
  87 
  88 text ‹Show that the two implementations are equivalent.›
  89 
  90 (*<*)
  91 (*Discuss how the automation fails because the induction hypothesis can be applied infinitely many
  92 times*)
  93 lemma rev'_append: "rev' xs ys = (rev' xs []) @ ys"
  94 proof (induction xs arbitrary: ys)
  95   case Nil
  96   then show ?case 
  97     by auto
  98 next
  99   case (Cons a xs)
 100   have 1: "rev' xs (a # ys) = (rev' xs []) @ (a # ys)"
 101     apply(subst Cons)
 102     ..
 103   have 2: "rev' xs [a] = (rev' xs []) @ [a]"
 104     apply(subst Cons)
 105     ..
 106   show ?case
 107     using 1 2
 108    by simp
 109 qed
 110 (*>*)
 111  
 112 lemma "rev_tr xs = rev xs"
 113 (*<*)
 114 proof(induction xs)
 115   case Nil
 116   then show ?case
 117     by auto
 118 next
 119   case (Cons a xs)
 120   then show ?case
 121     apply simp
 122     apply(subst rev'_append)
 123     by auto
 124 qed
