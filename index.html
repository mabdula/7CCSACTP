Module Overview:
This module introduces students to the state-of-the-art in computer-assisted mathematical theorem proving using the Isabelle/HOL interactive theorem prover (ITP). The curriculum progresses from logical foundations and functional programming, to the formal verification of software and mathematical theories, through to modern artificial intelligence and machine learning methods for automated reasoning.

Core Module Aims:
  • Foundations of ITPs: Higher-order logic, functional programming, algebraic datatypes, structural & computational induction, and proof automation (simplifier, sledgehammer, counter-example generators).
  • Software Verification: Formal semantics of programming languages, Hoare logic, and verifying practical software programs using frameworks such as AutoCorres2.
  • Formal Mathematics & Algorithms: Specification and verification of fundamental algorithms and data structures (sorting algorithms, search trees, graph algorithms).
  • AI & Machine Learning for Theorem Proving: Applications of modern LLMs, neural theorem provers, proof sketch generation, and agentic reasoning systems.
Intended Learning Outcomes (LOs):
  • LO1: (Theory) Differentiate logical foundations of modern ITPs and (Practice) proficiently interact with a mainstream ITP (Isabelle/HOL).
  • LO2: (Theory) Mathematically describe programming language semantics and (Practice) formalise them in an ITP to verify software.
  • LO3: (Theory) Mathematically describe and prove properties from mathematical domains/algorithms and (Practice) model them in an ITP.
  • LO4: (Practice) Use modern machine learning methods to assist in verifying software or formalising mathematical proofs.
  • LO5: (Practice) Engage with the state-of-the-art in theorem provers across software verification, mathematics, and modern machine learning approaches.

Teaching Format:
• Flipped Classroom: Pre-recorded lecture videos and reading materials prepare students for interactive Large Group Tutorials (LGT) and Small Group Tutorials (SGT).

Textbooks & Obligatory Reading Material (Freely Available Online):
• Functional Data Structures and Algorithms: Tobias Nipkow, Mohammad Abdulaziz et al. — fdsa-book.net
• Concrete Semantics: Tobias Nipkow & Gerwin Klein — concrete-semantics.org
• Isabelle/HOL Tutorial: Tobias Nipkow, Lawrence C. Paulson, & Markus Wenzel — isabelle.in.tum.de (PDF)

Assessment Structure (50% Coursework / 50% Exam):
• 50% Coursework: Individual formal proof project released on Friday, 30 October 2026 (Week 5) and due on Thursday, 10 December 2026, 4:00 PM (Week 10) (assessing practical LO1–LO5). Deliverables include: (1) Informal mathematical proof writeup (up to 2 pages), (2) Design decisions report (up to 2 pages), and (3) Mechanised proof theory file (.thy).
• 50% Exam: Paper-based written final examination in January 2027 (Examination Period 1), assessing theoretical foundations of LO1, LO2, and LO3.
